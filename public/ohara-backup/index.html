Ohara Backup

Ohara Backup is a private utility that saves encrypted backups of the owner's NAS application settings and databases to the owner's Google Drive. It uses rclone for Google Drive access and restic for encryption and backup storage. It is not a public backup service.

Privacy policy

Effective date: September 19, 2026.

Access and purpose

The app requests Google Drive access limited to files it creates or files explicitly made available to it (drive.file). It uses that access to upload, list, read, restore and manage encrypted backup files. It does not request access to Gmail, contacts or unrelated Drive files.

Data and storage

Backups contain selected NAS application configuration and database content. Restic encrypts backup content before upload. Encrypted backups are stored in the owner's Google Drive. OAuth credentials and authorization tokens are stored locally on the owner's devices for authentication; they are not published on this website. The owner must retain the backup encryption password separately to restore data.

Sharing and retention

Google processes stored files and API requests under its own policies. Backup data is not sold, used for advertising or shared with third parties by the operator. Backups are retained according to the owner's configured retention policy and can be deleted by the owner.

Control and contact

The owner can stop backups, revoke the app's access in Google Account settings, and delete backup files from Drive. Revoking access does not automatically delete existing backups. For questions, contact the operator through the L4igi GitHub profile.

This website

This informational page uses no analytics scripts, advertising or tracking cookies. It is hosted on GitHub Pages; GitHub may process connection information under its own privacy policy.

Terms of use

This utility is intended only for its owner's personal use and is provided as is, without a service-level guarantee. The owner is responsible for account security, backup passwords, storage availability and checking that backups can be restored. Google Drive use remains subject to Google's terms.
